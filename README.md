# Зошит шифрувальника — самостійна з функцій у Python

Онлайн-самостійна за матеріалом курсу Brilliant «Functions in Python», Level 1.
16 різних варіантів, 40 хвилин, код учня запускається просто в браузері,
а перевіряє роботу й записує результат Google Таблиця вчителя.

## Що бачить учень

1. Відкриває посилання, вписує на «обкладинці зошита» ім'я, прізвище та клас.
2. Отримує свій варіант. У межах класу варіанти не повторюються, поки не роздано всі 16;
   якщо учнів менше, зайві варіанти просто не використовуються.
3. Виконує 7 завдань і бонусне, код можна запускати скільки завгодно.
4. Натискає «Здати роботу» або робота здається сама, коли закінчиться час.

Якщо сторінка закрилася, учень відкриває її знову, вводить ті самі ім'я й клас і продовжує.
Час рахує сервер, тож перезавантаження сторінки його не зупиняє.

## Завдання в кожному варіанті

| № | Завдання | Що перевіряє | Бали |
|---|----------|--------------|------|
| 1 | Простеж програму | індекси й крок циклу `while` (без запуску) | 4 |
| 2 | Передбач і поясни | пастки: регістр, порядок `if/elif`, функція без `else`, код після `return` | 2 + пояснення |
| 3 | Тепер шифруєш ти | написати функцію `encode`, обернену до `decode` | 4 |
| 4 | Шифр змінився | оновити функцію під нові правила й розшифрувати відповідь | 4 + пояснення |
| 5 | Перевір код однокласників | чому функція краща за копіювання коду | 3 + пояснення |
| 6 | Збери програму | порядок рядків, відступи, два зайві рядки | 3 |
| 7 | Та сама навичка, інша задача | функція без шифрів: телефон, leet, цензор, імена файлів тощо | 4 |
| ★ | Бонус: свій шифр | власне правило щонайменше з двома умовами | 3 |

Автобал — до 24, бонус — до 3, за пояснення вчитель ставить до 6 (по 2 за завдання 2, 4, 5).
Оцінка за 12-бальною шкалою в таблиці рахується сама: `(автобал + бонус + пояснення) / 30 × 12`.

## Як захищено відповіді

- **На сторінці немає відповідей.** Учень отримує лише умову свого варіанта. Усі варіанти з ключами
  зберігаються тільки в Apps Script.
- **Бал рахує сервер.** Браузер надсилає те, що ввів учень, і результати запуску його коду на вхідних даних.
  Сервер порівнює їх із ключем, якого браузер ніколи не бачить.
- **Одна здача.** Повторна здача записується з позначкою «ПОВТОРНА» і не замінює першу.
- **Час на сервері.** Робота, здана пізніше ніж через 40 + 3 хвилини після старту, отримує позначку.

Чого технічно не закрити: учень може запустити код із завдання 1 чи 2 в редакторі іншого завдання
або скористатися телефоном. Тому пояснення «чому» — головна частина оцінки, а в таблицю приходить,
скільки разів учень виходив зі сторінки.

## Налаштування (один раз, ~3 хвилини)

1. Створіть Google Таблицю, наприклад «Самостійна: функції».
2. **Розширення → Apps Script**. Видаліть усе в редакторі й вставте весь вміст файлу `apps-script/Code.gs`. Збережіть.
3. **Розгорнути → Нове розгортання** → шестерня → **Вебзастосунок**. Виконувати як: **Я**. Хто має доступ: **Усі**.
4. **Розгорнути**, дозвольте доступ до таблиці, скопіюйте посилання, що закінчується на `/exec`.
5. Вставте посилання в `config.js` у рядок `SCRIPT_URL: "..."`.
6. Залийте файли в репозиторій GitHub і ввімкніть **Settings → Pages → Branch: main, / (root)**.

На GitHub потрібні лише `index.html`, `config.js` і `README.md`. Файл `apps-script/Code.gs` і `tools/key.md`
містять відповіді: **не публікуйте їх у публічному репозиторії**.

Аркуші «Учні» та «Результати» створяться самі при першому учні.

**Налаштування в Code.gs** (блок угорі): тривалість роботи, запас часу, чи показувати учню автобал.
Після змін: Розгорнути → Керування розгортаннями → олівець → Версія «Нова». Посилання не зміниться.

**Повторити самостійну в тому самому класі:** у редакторі Apps Script запустіть функцію `resetVariants`.

## Файли

- `index.html` — сторінка учня (без жодних відповідей).
- `config.js` — посилання на Apps Script.
- `apps-script/Code.gs` — сервер: усі варіанти з відповідями та перевірка. Не публікувати.
- `apps-script/Code.template.gs` — шаблон сервера для генератора.
- `tools/gen.py` — генератор варіантів; кожен еталон перевіряється запуском: `python3 tools/gen.py`.
- `tools/key.md` — ключ відповідей для вчителя. Не публікувати.
